# Fuelwatch EKB

Адаптивная статическая панель мониторинга цен на бензин на АЗС Екатеринбурга.
Проект работает без сборщика и внешних зависимостей.

## Запуск

Из корня репозитория запустите простой статический сервер:

```bash
python3 -m http.server 8000 --directory src
```

Затем откройте <http://localhost:8000>.

## Данные и API

Клиент сначала запрашивает безопасный same-origin adapter endpoint
`/api/gdebenz/stations`. Если adapter недоступен, интерфейс использует встроенный
набор демонстрационных данных и показывает это в статусе источника. Ключи и
секреты не нужны. Адаптер должен получать данные с `gdebenz.ru` на серверной
стороне и приводить их к формату:

```json
{
  "updatedAt": "2026-09-13T12:00:00Z",
  "stations": []
}
```

Каждая АЗС содержит `name`, `brand`, `district`, `address`, `distanceKm`,
`updatedAt`, `lat`, `lon` и массив `prices` с полями `fuel`, `label`, `price`.

Проверка источника показала, что `gdebenz.ru` доступен, но его API не публикует
CORS для произвольного frontend origin; прямой запрос из этого static-проекта
получает `403`. Поэтому приложение не парсит HTML сайта и не обращается к
закрытым API-маршрутам напрямую. Leaflet подключается с публичного CDN и не
требует API-ключа; карта с демо-маркерами остаётся доступной без backend.

## Проверки

```bash
node --check src/app.js
git diff --check
```

Данные в демо-режиме не являются официальной котировкой. Данные gdebenz.ru —
пользовательские отметки, а не проверенная сводка сетей АЗС. Для production нужно
подключить проверенный server-side adapter, настроить его обновление и отдельно
определить политику происхождения и актуальности данных.
